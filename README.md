Folder Size Controller

Customize the size of individual folders and notes in the Obsidian Graph View.

Folder Size Controller allows you to manually control how large each folder or note appears in your graph, giving you more freedom to organize and visualize your vault.

Features

Individual node sizing: Set a custom size for each folder and note.

Percentage-based scaling: Use percentages relative to the original node size.

Flexible values: Use any positive number, including decimals.

Automatic sizing compatibility: Manual sizes take priority over automatic subtree-based sizing.

Graph View integration: Works directly with Obsidian's Graph View.

How It Works

The size is configured as a percentage of the node's original size:

Value

Result

100%

Original size

150%

1.5x larger

50%

Half the original size

25%

One quarter of the original size

Installation

Download main.js and manifest.json from the latest release.

Create a folder named folder-size-controller inside your vault's .obsidian/plugins/ directory.

Place both files inside that folder.

Open Obsidian Settings → Community plugins.

Enable Folder Size Controller.

Configuration

Open Obsidian Settings.

Find Folder Size Controller.

Locate the Manual Node Sizes section.

Select a folder or note.

Enter your desired size percentage.

Compatibility

Designed for Obsidian's Graph View.
